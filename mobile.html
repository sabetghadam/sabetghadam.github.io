Engineering Approach

I treat a mobile app as a client of a larger system, not as an isolated UI. That means understanding the API contract, authentication, state management and error handling on the device, and how those depend on backend behaviour. I build and debug on physical devices rather than only on emulators, because real-device testing catches issues that an emulator will not. Across React Native, native Android and Xamarin.Forms work, my focus has been on shipping a mobile client that behaves correctly against its backend, not just on getting the screens to render.
